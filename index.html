Minecraft Modding

Mods are unofficial addons for the game Minecraft, written in the Java programming language. Java was my first programming language and I have been making mods since I was 13 years old. Over that time, I have developed my skills both as a Java developer and as a game designer.

My biggest mod to date is Classic Pipes, with over 2.5 million downloads, which implements an entire logistics system into the game for transporting and processing items. You can find the code for it on Github.
